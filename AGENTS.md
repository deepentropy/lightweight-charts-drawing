# AGENTS.md

Drawing tools for lightweight-charts v5 (TypeScript library, npm package `lightweight-charts-drawing`).

## Guide

Creating, changing, saving drawings, or adding a tool: read
[skills/lightweight-charts-drawing/SKILL.md](skills/lightweight-charts-drawing/SKILL.md) first.
It ships in the npm package, so it matches the installed version.

## Layout

```
src/core/      UI-free drawing core: model (types.ts), tool specs and defaults (specs.ts),
               placement / drag / Shift rules (interact/), scenes (scene/), hit tests and
               shared geometry (kinds/), saved-drawing migration (serialize.ts)
src/runtime/   DrawingManager (mouse, keys, events), makeCoords, canvas painter
src/index.ts   public exports
test/          vitest tests
skills/        agent guide, its examples (run by test/skill-examples.test.ts) and references
demo/          demo app (GitHub Pages)
docs/          TOOLS.md, generated by docs/tools_md.py
```

## Commands

```bash
npm ci
npm run typecheck   # library + skill examples + tests
npm test            # vitest
npm run build       # typecheck + dist/
npm run demo        # demo dev server
npx vitest run -u   # after a spec change: regenerate skills/.../references/tools.md
```

## Conventions

- The core imports only types from lightweight-charts and has no UI; the OpenTrader app uses
  `src/core` directly (SVG renderer), so keep core changes renderer-neutral.
- Drawings are stored in data space (`{ time, price }` points); pixels only at render time.
- Saved-format changes need a `migrateDrawing` case in `src/core/serialize.ts`.
- Every tool change: test in `test/`, CHANGELOG entry, regenerated tool references.
- Do not bump the version, tag or publish unless asked: a `v*` tag publishes to npm.
